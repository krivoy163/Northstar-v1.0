# INBOUNDS — Northstar v1.1

Northstar v1.1 deliberately leaves inbound creation in the 3X-UI panel. This avoids depending on undocumented/unstable automation and ensures each VPS gets fresh cryptographic material.

## General rules

- Use a different public port for each direct inbound.
- Generate fresh UUIDs and Reality keys for the new VPS.
- Do not reuse the first server's `x-ui.db`, private keys, UUIDs or client credentials.
- Add the same client identity to all three inbounds if you want one user's subscription to contain all three alternatives.
- After every change, export/test the link from a real external network.

## 1. VLESS Reality

Create a VLESS inbound using Reality security.

Record in your private admin notes:

- public port
- client UUID
- flow, if enabled
- Reality destination/SNI
- generated private/public key pair
- short ID

Use 3X-UI's generated Reality values rather than copying them from another server.

## 2. Hysteria2

Create a Hysteria2 inbound.

Remember that Hysteria2 uses UDP, so verify both the VPS/provider firewall and the OS firewall allow the selected UDP port.

Record:

- UDP port
- client credential generated by the panel
- TLS/SNI settings used by the inbound

## 3. VLESS XHTTP

Create a VLESS inbound with XHTTP transport.

Record:

- public TCP port
- client UUID
- XHTTP path
- mode/padding values if you choose to customize them
- TLS certificate/key paths when terminating TLS directly in Xray

For a direct TLS listener, use the certificate for the new server's domain.

## 4. Subscription

For each person, use a unique Sub ID. The 3X-UI subscription server will include supported enabled inbounds associated with that client.

After adding a user to all three inbounds, import only the single subscription URL into the client application and verify that all intended alternatives appear.

## Final external test

Do not call the VPS finished until:

- Reality connects.
- Hysteria2 connects over UDP.
- XHTTP connects.
- Subscription URL returns HTTP 200 and imports correctly.
- Rebooting the VPS leaves Nginx and x-ui active.
- A Northstar backup is created and copied off-server.
